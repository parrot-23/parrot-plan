# Parrot Plan

A weekly schedule planner plugin for Obsidian: built around a "week × 24 hours" grid, supporting time block planning, event scheduling, and execution tracking.


## Features (more on the way)

### 1 Time Blocks

A weekly planner that lets you lay out time blocks for each day, to plan time for different activities such as work, rest, and play.

### 2 Event Scheduling

Schedule tasks from the inbox to specific time slots, or create all-day events.

### 3 Execution Tracking

Review how your plans actually went, confirm or change execution, and view task execution records.

### 4 Linking Planned Events to Task Notes

Link planned events to task notes for easy access to task details and execution records.

### 5 Better Statistics

Provide more detailed task statistics, such as time usage and event distribution.
